Excel 단축키로 업무 효율성 높이기

2025-06-24

Excel을 사용하는 직장인이라면 단축키를 활용해 업무 효율성을 크게 높일 수 있습니다. 오늘은 가장 유용한 Excel 단축키들을 소개해드리겠습니다.

1. 기본 편집 단축키
• Ctrl + C: 복사
• Ctrl + V: 붙여넣기
• Ctrl + X: 잘라내기
• Ctrl + Z: 실행 취소
• Ctrl + Y: 다시 실행

2. 셀 이동 단축키
• Ctrl + 방향키: 데이터가 있는 마지막 셀로 이동
• Ctrl + Home: A1 셀로 이동
• Ctrl + End: 사용된 범위의 마지막 셀로 이동
• Page Up/Down: 화면 단위로 이동

3. 선택 단축키
• Ctrl + A: 전체 선택
• Shift + 방향키: 셀 범위 선택
• Ctrl + Shift + 방향키: 데이터가 있는 범위까지 선택

4. 서식 단축키
• Ctrl + B: 굵게
• Ctrl + I: 기울임꼴
• Ctrl + U: 밑줄
• Ctrl + 1: 셀 서식 대화상자

5. 수식 단축키
• F2: 셀 편집 모드
• Ctrl + Enter: 배열 수식 입력
• F4: 절대 참조 전환

이 단축키들을 매일 조금씩 연습하다 보면, 어느새 마우스 없이도 빠르게 작업할 수 있게 됩니다. 특히 반복적인 작업이 많은 분들에게 큰 도움이 될 것입니다.
