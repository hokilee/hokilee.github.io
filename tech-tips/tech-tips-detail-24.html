전자레인지 전자파 걱정? 문 잘 닫히면 안전

2024-07-15

전자레인지를 사용할 때 전자파가 새어나올까 걱정하는 분들이 많지만, 실제로는 문이 제대로 닫혀 있다면 전자파가 거의 새지 않습니다.

🔬 전자레인지의 안전 설계

• 금속망(실드) 내장: 전자파가 외부로 빠져나가지 않도록 설계
• 자동 차단: 문이 열리면 전자파 발생이 즉시 멈춤
• 정기 점검: 문이 헐겁거나 고장난 경우 즉시 점검 필요

💡 안전하게 사용하는 방법

1. 문이 잘 닫혔는지 항상 확인
2. 문에 이물질이 끼지 않도록 주의
3. 문이 헐겁거나 손상되면 사용 중지 후 수리

⚠️ 잘못된 사용 시 주의점

• 문이 완전히 닫히지 않으면 전자파가 일부 새어나올 수 있음
• 문이 손상된 상태로 사용하면 안전에 위험
• 임의로 전자레인지 내부를 분해하지 말 것

전자레인지 전자파는 일상적인 사용 환경에서는 인체에 해를 끼치지 않으니, 문이 잘 닫힌 상태에서 안심하고 사용하세요!
